## 🛠️ 製作流程 / Production Workflow

### 步驟
1. **研究 / Research** — 引用 Wikipedia、MILSPEC、Jane's
2. **草圖 / Sketch** — 紙筆, 3 視圖
3. **建模 / Model** — Blender (複雜) 或 Tinkercad (簡單)
4. **紋理 / Texture** — PBR 材質
5. **動畫 / Animation** — 移動、武器發射
6. **匯出 / Export** — .glb, .fbx, .obj
7. **嵌入 / Embed** — Story Maps, GitHub Pages

### 工具選擇
| 難度 | 工具 | 費用 |
|------|------|------|
| 初學 | Tinkercad | 免費 |
| 中 | SketchUp | 免費版 |
| 中高 | Fusion 360 | 教育版免費 |
| 高 | Blender | 免費 |
| 專業 | Maya / 3ds Max | 商業 |

## 📦 輸出格式 / Output Formats

- **.glb** — Web 通用 (Story Maps、Three.js)
- **.fbx** — Unity、Unreal Engine
- **.obj** — 通用
- **.stl** — 3D 打印
- **.usdz** — Apple AR Quick Look

## 🎨 設計原則 / Design Principles

1. **歷史準確 / Historical Accuracy** — 比例、顏色、標記
2. **可識別 / Recognizable** — 觀眾一眼認得
3. **可縮放 / Scalable** — LOD (level of detail)
4. **可互動 / Interactive** — 旋轉、爆炸、剖面
5. **可分享 / Shareable** — GitHub LFS, web 嵌入

## 袁騰飛式點評 / Sharp Observation

> 3D 模型嘅最大作用:**「將抽象嘅軍事分析,變成可被觸摸嘅歷史」**。
> 一個航母模型,可以話俾人聽「咩係 10 萬噸」;
> 一個 M1 Garand, 可以話俾人聽「二戰點樣靠半自動步槍贏」;
> 一個 F-35, 可以話俾人聽「點解一架飛機值 1 億美元」。
> **武器唔只係金屬,而係戰略嘅物質化。**
> **3D 模型,就係令戰略變得可見。**
