## 5 個核心心智模型 / 5 Core Mental Models

1. **帝國節奏 / Imperial rhythm** — 擴張、收縮、鞏固嘅 30-40 年週期
2. **島鏈戰略 / Island chain strategy** — 第一、第二島鏈嘅地緣控制
3. **技術-制度耦合 / Tech-institution coupling** — 武器變革推動基地、條約、聯盟嘅調整
4. **同盟體系 / Alliance system** — 雙邊(美日、美韓)→三邊(AUKUS)→多邊(QUAD)
5. **記憶政治 / Memory politics** — 邊個歷史被記住決定邊個基地被接受

## 3 個根本分歧 / 3 Fundamental Disagreements

### 分歧 1:美軍亞洲部署 — 帝國 vs 秩序 / Empire vs Order
- **A:** 帝國 — 菲律賓 1898-1946 證明美國係殖民者,現代基地網絡係非正式帝國
- **B:** 秩序 — 二戰後美軍喺亞洲係阻止蘇聯擴張、維護國際秩序,唔係傳統帝國

### 分歧 2:島鏈戰略 — 必要 vs 過時 / Necessary vs Obsolete
- **A:** 必要 — 中國反介入/區域拒止(A2/AD)能力提升,第一島鏈仍然係威懾基礎
- **B:** 過時 — 導彈、航母、無人機已經削弱島鏈意義,未來係分散式部署

### 分歧 3:QUAD/AUKUS — 遏制中國 vs 自身目的 / Containment vs Self-purpose
- **A:** 遏制 — 目的係平衡中國崛起、保護台灣、維護南海航行自由
- **B:** 自身 — 美國自身工業基礎、就業、政治需要先決定軍事部署,中國只係藉口

## 袁騰飛式犀利觀察 / Sharp Observation

> 美軍喺亞洲嘅 130 年歷史,**唔係一條直線,而係 4 個 30 年週期**:
> 1. **1898-1930:** 菲律賓佔領 + 對日戰略觀察
> 2. **1945-1975:** 冷戰部署高峰 (日本、韓國、台灣、越南、菲律賓)
> 3. **1975-2001:** 後越戰收縮,集中第一島鏈
> 4. **2001-2026:** 反恐 → 大國競爭,QUAD/AUKUS 重啟多邊
>
> **第四個週期嘅核心矛盾:中國已經強大到島鏈無效,但美國又唔想承認。**
