# 06_Integration_Matrix

**92 個 HKU + Harvard History Courses → 應用出口對照表**
**92 Courses → Application Output Mapping Matrix**

> 將所有 92 個 history course 同 5 個輸出子資料夾 (Timelines、Bases、Weapons、StoryMaps、3D) 連接。
> 展示**歷史學問**如何**轉化為**具體嘅軍事分析產出。

---

## 📊 連接框架 / Connection Framework

每個 course 通過以下路徑連接到項目:

```
Course 嘅 5 心智模型 + 3 分歧 + 10 問題
    ↓ 抽象歷史洞察
Course 嘅 5 Deep Dives (1.1-1.5 概念對照、史料、點評、題目、圖)
    ↓ 具體歷史內容
應用出口 (04_US_Military_Weapons_Asia)
    ↓
5 個子資料夾 (Timelines、Bases、Weapons、StoryMaps、3D)
```

## 🧭 導航路徑建議 / Navigation Recommendations

### 從 Course 出發
1. 揀一個你最有興趣嘅 history course
2. 讀其 5 deep dives
3. 喺上面矩陣揾到佢對應嘅 sub-folder
4. 睇嗰個 sub-folder 嘅 .md 文件
5. 製作 Story Map 或 3D Model

### 從 Project 出發
1. 揀一個 Story Map (例如 7 — AUKUS)
2. 睇佢嘅「對應 Course」部分
3. 揀 2-3 個最深嘅 course 讀其 deep dives
4. 結合你嘅歷史背景,改良 Story Map
5. 創建對應嘅 3D Model

## 袁騰飛式點評 / Sharp Observation

> 92 個 courses 唔係「學術消費品」,係**工具箱**。
> 呢個 04_US_Military_Weapons_Asia 資料夾就係**工作枱**。
> 工具 + 工作枱 = 產出。
> 產出 = Story Maps + 3D Models + 政策建議。
> **單讀 course 唔夠,要從 course 走到 project;單做 project 唔夠,要從 project 返到 course。**
> 雙向來回,先至係真正嘅歷史學。
