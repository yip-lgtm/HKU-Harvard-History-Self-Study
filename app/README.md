# HKU + Harvard History 自動化自學 App

## 功能

- 課程列表（Harvard Foundations + HKU + Fall）
- 優先級篩選（★★★★★ / ★★★★ / 已完成 / 未完成）
- 搜尋課程代碼與名稱
- 每門課標準三層深度問答：
  1. 5 個核心心智模型
  2. 3 個根本分歧點
  3. 10 個深度理解問題
- 進度儲存（瀏覽器 Local Storage）
- 一鍵匯出 Markdown
- 整體完成度統計

## 使用方式

### 本地開啟
直接用瀏覽器打開 `app/index.html` 即可。

### GitHub Pages
若已啟用 Pages，可訪問：
```
https://yip-lgtm.github.io/HKU-Harvard-History-Self-Study/app/
```

## 設計原則

- 零依賴（純 HTML + CSS + JS）
- 離線可用
- 資料存在瀏覽器，不需後端
- 對齊research-based深度問答結構
- 服務 US Military Weapons Project 核心研究
