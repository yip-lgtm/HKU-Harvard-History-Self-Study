### 分歧 1：清認同 — 漢化 vs 滿洲 / Qing Identity — Sinicized or Manchu
**核心問題 / Core question**: 清朝是中國傳統王朝的延續還是滿洲殖民政權？

- **一方觀點** / **Side A**: A: 漢化 — 康熙雍正乾隆全面接受儒教，承襲科舉
- **另一方觀點** / **Side B**: B: 滿洲 — 八旗制度、滿文、內亞性保留，New Qing History 強調滿洲獨特性

### 分歧 2：朝貢體系 — 真實 vs 神話 / Tribute System — Functional or Mythical
**核心問題 / Core question**: 朝貢體系是真實的國際秩序還是中國中心主義的神話？

- **一方觀點** / **Side A**: A: 真實 — 規範明確、互市貿易、定期使節
- **另一方觀點** / **Side B**: B: 神話 — 現代學者建構的，實際運作混亂

### 分歧 3：鴉片戰爭 — 文明衝突 vs 帝國侵略 / Opium War — Civilizational Clash or Imperialist Aggression
**核心問題 / Core question**: 第一次鴉片戰爭是文明衝突還是帝國主義侵略？

- **一方觀點** / **Side A**: A: 衝突 — 中國閉關自守，必須打破

1. **權力結構永遠比意識形態更持久**：{name_en} 真正的驅動力是誰掌握了槍、錢、人。
