### 分歧 1：監獄 — 改革 vs 控制 / Prison — Reform or Control
**核心問題 / Core question**: 現代監獄起源是改革理念還是社會控制？

- **一方觀點** / **Side A**: A: 改革 — 邊沁圓形監獄設計人道
- **另一方觀點** / **Side B**: B: 控制 — 監視、規訓、資本主義勞動

### 分歧 2：殖民地監獄 — 文明化 vs 殘酷 / Colonial Prison — Civilizing or Brutal
**核心問題 / Core question**: 殖民地監獄是帝國文明使命還是殘酷鎮壓？

- **一方觀點** / **Side A**: A: 文明化 — 傳播法治
- **另一方觀點** / **Side B**: B: 殘酷 — 安汶島苦役、剛果橡膠暴行

### 分歧 3：大規模監禁 — 美國模式 / Mass Incarceration — US Model
**核心問題 / Core question**: 美國 2 百萬囚犯是法治還是社會病？

- **一方觀點** / **Side A**: A: 法治 — 嚴刑峻法
- **另一方觀點** / **Side B**: B: 社會病 — 種族、貧窮、毒品戰爭的綜合症
